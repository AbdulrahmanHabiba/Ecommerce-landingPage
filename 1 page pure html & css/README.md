# SolarWave - Solar Panel Installation Landing Page

## Overview
A modern and attractive landing page for a company specializing in solar panel installation. The page is designed using pure HTML, CSS, and JavaScript without any external frameworks.

## Features
- Modern and attractive design with colors suitable for the solar energy field
- Responsive interface that works on all screen sizes
- Elegant navigation bar with a mobile menu
- Hero section with statistics and an attractive image
- Modern fonts from Google Fonts
- Icons from Font Awesome
- Simple animation effects when scrolling

## Technologies Used
- HTML5
- CSS3 (with CSS variables)
- Pure JavaScript
- Google Fonts
- Font Awesome

## How to Run
Open the `index.html` file in any modern web browser to view the page.
